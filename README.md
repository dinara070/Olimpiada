# Olimpiada

Структура розділів сайту
1. Головна сторінка (🏠 Home)
- Hero-секція: Привітальний банер із градієнтним фоном, назвою олімпіади та ключовими тегами (дата, формат, класи).
- Зворотний відлік: Динамічний таймер, який рахує дні, години, хвилини та секунди до старту олімпіади (задано на 15 листопада 2026 року).
- Інформаційні картки: Короткі блоки-плитки з основною інформацією (хто може брати участь, формат, мови, нагородження).

2. Про олімпіаду (📖 About)
- Історія та місія: Текстовий блок про заснування змагання та його рівень.
- Блок статистики: Відображає кількість років існування, країн-учасниць та загальну кількість учасників.
- Профіль засновника: Стилізована картка «Професора Геометрія».
- Правила: Детальний перелік умов участі (формат змагання, подання розв'язків, заборонені інструменти).

3. Розклад (📅 Schedule)
- Таймлайн подій: Візуальна шкала часу, що відображає ключові етапи: від відкриття реєстрації та публікації пробних задач до дня олімпіади (виділено окремим кольором) та оголошення результатів.

4. Архів (📚 Archive)
- Історія змагань: Картки минулих олімпіад (з 2020 по 2025 рік).
- Статистика кожної події: Кількість задач, учасників та країн.
- Кнопки взаємодії: Заглушки для завантаження умов, розв'язків та результатів минулих років.

5. Результати (🏆 Results)
- Система вкладок (Tabs): Окремі вкладки для результатів різних років (2025, 2024, 2023) та загальної статистики.
- Турнірні таблиці: Кастомні HTML-таблиці, які показують місце, ім'я, країну, бали за кожну задачу, загальний бал та тип нагороди.
- Статистика: Аналітика росту учасників, географія та середні бали.

6. Реєстрація (📝 Register)
- Форма зворотного зв'язку: Використовує st.form для збору даних майбутніх учасників (ім'я, email, країна, навчальний заклад, клас, бажана мова).
- Валідація: Перевірка заповнення обов'язкових полів. У разі успіху викликається анімація st.balloons() та повідомлення про успішну реєстрацію.
